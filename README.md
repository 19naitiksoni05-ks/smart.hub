# 🚀 Smart Hub (`smart.hub`) — India's Premier Digital Product Marketplace & Developer Community

> **Buy, Sell, Connect & Build Together.**  
> Built specifically for Indian developers with ₹ INR currency, encrypted email project delivery, Spotify-style discovery, Discord & Reddit-style community channels, Telegram & WhatsApp-style messaging, LinkedIn & Instagram-style developer feed, and real-world skill challenges.

---

## 🌟 Key Features Overview

### 1. 🛒 Digital Product Marketplace (CodeCanyon-style)
* **Explore & Filter**: 10,000+ digital products including React apps, Flutter templates, AI tools, UI kits, WordPress themes, and backend scripts.
* **Pricing in ₹ INR**: Authentic Indian Rupee pricing with discounts and badge indicators (Bestseller, Hot, New, Featured).
* **Grid & List Views**: Dynamic view switching with search, category filtering, and price range sliders.
* **Instant Product Modal**: Detailed previews, tech stack tags, reviews, ratings, and one-click purchase flow.

### 2. 🔐 Wallet-Based Payment & Encrypted Delivery
* **Pre-funded Wallet**: Seamless two-way wallet system (Add money via UPI, Net Banking, Cards; receive earnings from project sales).
* **Zero Transaction Fees**: 100% value retention on top-ups and seller earnings.
* **Encrypted Email Delivery**: Every purchased product generates an end-to-end encryption key (`SH-ENC-...`) sent directly to the buyer's verified email.

### 3. 🎵 Spotify-Style Discovery Hub
* **Curated Carousels**: *For You*, *Popular*, *Latest Drops*, and *On Sale* horizontal smooth-scrolling shelves.
* **Category Showcase**: Quick category cards with live product counts.
* **Live Community Leaderboard**: Real-time developer ranking with XP points and achievement medals.

### 4. 💬 Community Platform (Discord + Reddit Hybrid)
* **Server & Channel Architecture**: Multi-server sidebar (`#general`, `#react`, `#flutter`, `#showcase`, `#help`).
* **Interactive Message Threads**: Real-time replies, emoji reactions (🔥, 🏆, 🚀), and pinned announcements.
* **Online/Offline Member Directory**: Live presence indicators and roles (Admin, Moderator, Member).

### 5. ✉️ Real-Time Chat System (Telegram + WhatsApp)
* **Direct Messages (DMs)**: Private 1-on-1 chats with read receipts and typing status.
* **Groups & Channels**: Dedicated broadcast channels and dev groups with member counts.
* **Rich Interactions**: Voice note indicators, media attachments, code snippets, and automated interactive replies.

### 6. 📰 Developer Feed & Forum (LinkedIn + Instagram)
* **Story Highlights**: Top developer stories strip with active gradients.
* **Post Creator**: Rich post creation with code snippets, tags, and media uploads.
* **Engagement Feed**: Like, comment, share, bookmark, and follow fellow developers.

### 7. 👤 Developer Profile & Portfolio (GitHub-style)
* **52-Week Contribution Heatmap**: Interactive GitHub-style commit grid.
* **Showcase Repositories**: Star ratings, fork counts, and primary language indicators.
* **Skill Badges & Levels**: Verified seller badge, XP progress bar, and tech stack badges.
* **Project Publisher**: Direct modal to list new products on the marketplace.

### 8. 🏆 Skill Challenges & Growth Tracker
* **Real-World Project Briefs**: Full-stack dev challenges with difficulty tiers (Easy, Medium, Hard).
* **XP & Rewards System**: Earn XP points and unlock badges (React Pro, AI Builder, Problem Solver).
* **Live Daily Countdown**: 24-hour countdown timer for daily coding sprints.

## 🚀 How to Run Locally

Because this project is built using modern standard HTML5, CSS3, and JavaScript:

1. **Direct Browser Access**:
   Double click or open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari).
   
2. **Local Live Server (VS Code / Python / Node)**:
   - If using VS Code: Right-click `index.html` and click **"Open with Live Server"**.
   - If using Python:
     ```bash
     python -m http.server 3000
     ```
     Navigate to `http://localhost:3000`.
   - If using `npx serve`:
     ```bash
     npx serve .
     ```
